# Virtual Drive Center — 项目规划

作者：Michael

## 项目愿景

将 Synology NAS 上的 ISO / IMG 文件管理、检查、挂载和文件访问统一到一个现代化 Web 控制台中，同时保持 DSM File Station 的实际文件系统可访问性。

## 现阶段目标

当前 2.0.x 版本以“稳定、可用、可诊断”为第一目标：

- NAS 内部选择
- 电脑上传
- ISO / IMG
- MBR/GPT 分区识别
- 多分区手工选择
- 常见文件系统状态识别
- RO / RW
- SHA-256
- 挂载历史
- Web 文件操作
- DSM File Station 路径
- 大容量映像的进度与状态

## 2.1 规划

### 文件管理

- 双栏/三栏 NAS 文件浏览器
- 多选
- 批量复制
- 批量删除
- 右键菜单
- 拖拽上传到挂载分区

### 挂载中心

- 活动任务中心
- 批量挂载/卸载
- 自动释放异常 loop
- 更细致的挂载诊断
- 挂载耗时统计

### 可视化

- 映像占用统计
- 挂载容量统计
- 文件系统状态图
- 历史趋势

## 2.2 规划

- 文件系统兼容性矩阵
- 更完整的健康检查
- 多用户
- 权限控制
- API Token
- 操作审计
- Webhook

## 长期方向

- ISO 修改与重新生成
- 镜像转换
- API 集成
- 多 NAS 节点
- 可选的网络块设备功能

## 版本原则

每个版本优先解决：

1. 数据安全。
2. NAS 兼容性。
3. 挂载可靠性。
4. 可观测性。
5. UI 可用性。

新功能不应以破坏已经验证可用的 DSM File Station 工作流为代价。
